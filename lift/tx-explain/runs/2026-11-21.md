**The held-out tasks this run used were picked by rule `block-hash-v1`**, kept as
`lift/tx-explain/held-out/block-hash-v1.json`. Its swap task (Base block 52953379) showed two flaws in that rule:

- The transaction is a liquidity deposit with a position NFT. The chain reader calls any transaction that moves two
  tokens a swap, and it does not count an NFT's Transfer log.
- The task checked how many movements the answer lists, which fails an answer that also names the NFT.

Neither changed this run's counts: the answer with the skill got both token amounts wrong, and the other was cut off.
The rule is now `block-hash-v2` (no Transfer log the reader does not count; a swap only when the sender gave one token
and got another; the count checked only when nothing moved). `lift/tx-explain/held-out.json` holds its picks: the same
first four tasks, and another swap (block 52953390). No run has been made on them.
